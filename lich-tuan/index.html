Hướng dẫn sử dụng

  1. Cài đặt một lần (nút bánh răng): tên đơn vị, ký hiệu văn bản, người ký, nơi nhận, giá trị điền sẵn. Nên chọn luôn thư mục lưu file để mỗi lần xuất Word là file nằm sẵn trong thư mục đó.
  2. Chọn tuần bằng ◀ ▶ hoặc "Chọn tuần…". Ngày Thứ Hai → Chủ Nhật, tuần thứ mấy trong tháng và số văn bản (tăng tiếp theo tuần trước) được tính tự động.
  3. Đã có lịch bằng Word? Kéo thả file .docx vào cửa sổ (hoặc bấm "Nhập từ Word"): ứng dụng đọc bảng lịch, số văn bản, ngày tháng và đưa vào đúng tuần. Có thể thả nhiều file một lúc.
  4. Nhập công việc: bấm "Thêm" ở từng ngày. Các ô có gợi ý từ những lần nhập trước (↑ ↓ rồi Enter để chọn). Ô có thể xuống dòng bằng Enter, VD Địa điểm: "- Ấp Thạnh Nghĩa" ↵ "- Ban CHQS xã".
  5. Thời gian gõ nhanh "8h20-9h30", "14:00 - 15:00", "0730-0800" → tự chuẩn hóa thành "08h20 - 09h30".
  6. Sắp xếp: kéo nút số thứ tự để đổi vị trí (kể cả sang ngày khác), hoặc dùng mũi tên, "Chuyển…", "Theo giờ".
  7. Việc lặp lại (giao ban, sinh hoạt…): bấm ngôi sao để lưu làm mẫu, "Sao chép từ tuần trước", hoặc tìm (Ctrl+K) rồi chép lại.
  8. Xuất Word: ứng dụng kiểm tra thiếu nội dung, thiếu giờ, trùng giờ trước khi xuất. File đúng mẫu: A4 ngang, Times New Roman, tiêu đề bảng lặp lại mỗi trang, số trang từ trang 2.
  9. Dữ liệu lưu tự động trên máy (2 lớp trong trình duyệt). Vẫn nên sao lưu định kỳ (menu ⋮) – ứng dụng sẽ nhắc khi quá 7 ngày chưa sao lưu.

Dùng trên điện thoại

  1. Cách tốt nhất: mở địa chỉ web của ứng dụng rồi cài vào màn hình chính (Android/máy tính: menu ⋮ → "Cài ứng dụng"; iPhone: Safari → nút Chia sẻ → "Thêm vào MH chính"). Sau khi cài, ứng dụng mở như app riêng và chạy được khi không có mạng.
  2. Hoặc chép file ứng dụng (.html) sang điện thoại và mở bằng Chrome (Android) hoặc Safari (iPhone). Giao diện tự chuyển sang dạng điện thoại: thanh chức năng ở cuối màn hình, chạm vào công việc để sửa.
  3. Đưa dữ liệu từ máy tính sang: trên máy tính bấm Chuyển dữ liệu → chọn tuần hoặc Toàn bộ dữ liệu → Lưu file .json, gửi file qua Zalo/email; trên điện thoại bấm Chuyển dữ liệu → Nhập file .json. Làm ngược lại để đưa lịch lập trên điện thoại về máy tính.

Chức năng

Chuyển dữ liệu máy tính ⇄ điện thoại

  1. Trên máy gửi: chọn dữ liệu cần chuyển rồi bấm Lưu file .json.
  2. Gửi file sang máy kia (Zalo, email, cáp USB…).
  3. Trên máy nhận: mở ứng dụng → Chuyển dữ liệu → Nhập file .json.

Nhập dữ liệu

Chọn file .json nhận được từ máy khác. Các tuần trong file được thêm vào ứng dụng; nếu trùng với tuần đã có dữ liệu, ứng dụng sẽ hỏi trước khi ghi đè. Trên máy tính có thể kéo thả file vào cửa sổ.
